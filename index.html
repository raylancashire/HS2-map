Minimum Sheet column: Address. Postcode is strongly recommended. Optional Photos column: HTTPS image URLs separated by |. Latitude/Longitude are optional: missing coordinates are looked up and cached in the browser.

Manual pinpoint editor

Choose an existing property to correct its location, or enter a new address. Drag the existing marker or click a building to reposition it.

Safari backup: if the download does not start, click Copy CSV, or select the text below and copy it into a text file saved as hs2-property-pinpoints.csv.

Saved pinpoints remain in this browser. Download the CSV to keep a permanent copy; import it into your Google Sheet to share corrected locations with everyone.

Tunnel route versions

Select a saved route version. Property distances and the 30 m corridor follow the selected alignment.

To make a route permanent, upload its GeoJSON file and add an entry in routes.json. The public page can select published versions.

Compare twin tunnels

Select a published second route to compare.

The blue dashed alignment is a comparison overlay only. Distances and property colours remain based on the Displayed alignment.

Tunnel route editor

Drag the tunnel line’s control points to adjust the provisional alignment. Download the updated GeoJSON and replace hs2-route.geojson in GitHub to publish changes.

Generate parallel alignment

Creates a new alignment from the selected route. Preview replaces the displayed route until reset or another version is selected. Download it as a separate GeoJSON version to keep the original.
